# CS357_FinalProject

Initial Steps:
- Choose a good coding program to run the application (VSCode Recommended)
- Haskell MUST be downloaded for the program to run
- Git clone and pull the repository onto your program of choice
- run the command "cabal update" then "cabal build

To use the program:
- Run "cabal wic-ui" or "cabal wic-cli" (preference of UI)

In terminal:
- Type username of your choice.
- Follow the controls provided by the GUI, one-character instruction should be given to terminal to use the application

- Have fun!
